# Pyosition

삶을 통제 가능한 시스템으로 만드는 플래너 앱

## 개요

Pyosition은 **Daily S (상태)**, **Weekly I (중요도)**, **Quarterly R (리밸런싱)**의 3단계 시스템으로 인생의 각 영역을 체계적으로 관리하는 iOS 앱입니다.

## 주요 기능

### 🎯 4개의 메인 탭

1. **홈** - 오늘의 상태와 이번 주 중요도 한눈에 보기
   - 이번 주 중요도 (격자형)
   - 오늘의 집중 모듈 (I=3)
   - 오늘의 상태 요약
   - 바텀시트로 빠른 상태 기록

2. **계획** - 주간 중요도 배정
   - 지난 주 평균 (캐러셀)
   - 중요도 배정 (컴팩트 슬라이더)
   - I=3는 최대 2개까지만 선택 가능

3. **통계** - 리포트 및 히스토리
   - 주간/분기 리포트
   - 실시간 활동 히스토리 (자동)

4. **더보기** - 모듈 관리 및 설정
   - 모듈 추가/수정/삭제
   - 해석 정책 설정
   - 사용법 및 가이드
   - 데이터 초기화

### 🎨 핵심 개념

#### Daily S (상태 기록)
- -2 ~ +2 범위의 5단계 평가
- 슬라이더 UI로 직관적 입력
- 날짜 선택 팝업으로 과거 기록 가능
- 각 모듈별 메모 작성

#### Weekly I (중요도 배정)
- 0 ~ 3 범위의 중요도
- I=3 (최우선)는 최대 2개까지만
- 지난 주 평균을 참고하여 배정
- 캐러셀로 스와이프하며 확인

#### Quarterly R (리밸런싱)
- 분기별 평균 점수 확인
- 극단적 상태 알림
- 모듈 우선순위 재조정

### 🧩 해석 정책

각 모듈은 3가지 해석 정책 중 하나를 선택:

1. **최적대역형** - 0에 가까울수록 좋음
   - 예: 체중, 혈압

2. **적을수록 좋음** - -2가 최고, +2가 최악
   - 예: 지출, 스트레스

3. **많을수록 좋음** - +2가 최고, -2가 최악
   - 예: 운동, 수입

### 📊 실시간 히스토리

- 모든 상태 기록이 자동으로 히스토리에 저장
- 중요도 배정 내역도 실시간 반영
- 수동 로그 생성 불필요
- 상대 시간 표시 (예: "3분 전")

## 기술 스택

- **언어**: Swift
- **프레임워크**: SwiftUI
- **아키텍처**: MVVM
- **데이터**: UserDefaults (완전 로컬)
- **최소 버전**: iOS 15.0+

## 빌드 및 실행

1. Xcode 설치 (14.0 이상 권장)
2. 프로젝트 열기:
   ```bash
   open Pyosition/Pyosition.xcodeproj
   ```
3. 시뮬레이터 또는 실제 기기 선택
4. ⌘+R로 실행

### pyophone 실기기 빌드

1. Xcode에서 Signing & Capabilities 설정
2. Team 선택
3. Bundle Identifier 확인
4. 기기 연결 후 빌드

## 데이터 관리

### 데이터 초기화
설정 > 데이터 > 모든 데이터 초기화
- "초기화" 입력으로 확인 필요
- 모든 기록, 모듈, 설정 삭제
- 온보딩 화면 다시 표시

### 백업
- UserDefaults에 저장
- iCloud 백업 자동 지원 (iOS 설정)
